# 3.3.14 发布前检查

作者已确认测试包通过，本次将建档可靠性、参数契约、PC/手机草稿状态与消息时间线修复一并发布为 3.3.14。

发布检查发现并处理了现有代码的工程门禁问题：

- 将建档状态投影从执行器移到 `cataloging/projection.py`，事务停止请求移到 `cataloging/runtime_requests.py`，消除观察器、执行器和任务控制的循环引用。
- 场景候选替换归入候选存储，场景契约只负责读取与校验；候选合并提取到独立模块，所有入口引用同一实现。
- 拆分候选校验、进度渲染、失败结果封装和模型响应完成处理，保持原有事务、工具结果与事件顺序。没有放宽架构基线。
- 将建档页面的可见性与观察连接生命周期提取为功能层 hook。建档启动失败测试等待按钮恢复可用后再重试，避免异步加载状态造成误报。

本地验证结果：

- 建档、外部写章、大纲、模型流式调用与相关修复：529 项通过。
- 发布安装契约、配置、立项、手机提示词与两端契约：197 项通过。
- 前端全量测试：304 项通过；页面生命周期提取后的建档页面回归：7 项通过。
- Android 全量单元测试：292 项通过；`lintDebug` 通过。
- 后端质量检查、前端 lint、架构边界、重复代码门禁、生产构建、OpenAPI 类型同步和性能基线通过。

正式 Windows 安装包与 Android 签名 APK 由标签发布流水线生成。流水线执行安装冒烟、附件校验及发布后重新下载验证；其执行结果以 GitHub Actions 为准。

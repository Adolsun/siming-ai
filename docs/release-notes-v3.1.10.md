# Siming 3.1.10

Siming 3.1.10 延续 3.1.9 的对话式立项可靠性修复，并补齐 Gateway 多架构发布闭环。

## 主要变化

- 适配 DeepSeek V4 Flash/Pro 正式接口默认开启思考模式的变化：普通聊天使用可识别 `reasoning_content` 的完整思考流并提高输出预算，若模型只返回思考而没有最终正文则自动以非思考模式恢复一次；短 JSON 动态采访仍明确关闭思考，避免浪费结构化输出预算。
- 任务中心红点改为未读提醒计数，可一键“全部标为已读”；历史待处理任务仍保留在任务中心，不再永久占用红点。
- “最近活动”改为明确的本地时间戳，不再显示“32 小时前”等相对时间。
- 立项工具全部升级为类型化输入契约；确认当前内容与“确认并继续”均可安全重复点击，后者只创建一个推荐对象任务。
- 失败任务明确提供“按原输入重试”和“按最新内容重试”；旧任务遇到作者新修改时保留候选稿并显示版本冲突，不覆盖当前内容。
- 等待作者确认的任务不再显示暂停或取消操作，避免对已经结束模型执行的任务发出无意义控制。
- 保留 3.1.9 的全部对话式立项改进：统一 `waiting_user`、持久暂停/继续/取消/重试、原子“确认并继续”、聊天确定性控制和完整模型诊断。
- Gateway 的前端静态资源改为在 BuildKit 的 `$BUILDPLATFORM` 上构建；最终 Python runtime 仍按目标架构生成。
- arm64 镜像不再通过 QEMU 执行 `npm ci`，避免发布 runner 长时间无进度，同时不改变最终前端产物。
- 桌面、Android 与 Gateway 版本统一为 3.1.10；Android `versionCode` 为 `30110`。

## 发布验证

- 前端 lint、单元测试、架构/重复检查、API 类型检查、生产构建与 Playwright E2E。
- 后端全量测试、迁移演练与性能基线。
- Windows EXE 打包、版本/哈希一致性与实际启动烟测。
- Android 单元测试、lint、签名 APK、证书、manifest、zipalign 与 SHA-256。
- Gateway linux/amd64 与 linux/arm64 构建、非 root/可写数据烟测及多架构镜像发布。

# 司命 3.2.0

3.2.0 聚焦长篇小说创作闭环、建档一致性、本地 CLI 能力对齐，以及关键交互的可理解性与可控性。

## 主要改进

- 将章节写作、去除 AI 味和质量评分拆成独立操作，用户可以按需要手动触发，不再把多轮后处理强塞进一次写作任务。
- 正式作品新增创作设定入口，可持续维护创作约束、创意方向和文风；项目助手也能读取和更新这些数据，使其真正影响后续创作。
- API 与本地 CLI 共用同一套作品建档应用链路，统一章节摘要、角色、世界观、大纲、关系和叙事治理的落库行为。
- 改进建档候选生成、空候选过滤、别名归一、角色类型枚举、覆盖校验与自动模式，减少脏卡、重复重试和不必要的人工审核。
- 补齐卷—章—场景大纲层级，并改进章节逐章建档、断点恢复和历史任务展示。
- 完善叙事治理生命周期、证据记录和原文定位，支持从治理项准确回到对应章节位置。
- 快速开始在已有可用模型后复用验证结果，避免反复探测模型。
- 外部 CLI 的 MCP 配置改为用户主动触发、逐项配置与还原；移除旧写后归档工具，章节保存后统一启动现行建档流程。
- 修复外部 `.env` 污染、旧数据库迁移、输入文件路由、任务删除与多处立项/聊天状态同步问题。

## 发布资产

- `Siming.exe`：Windows 桌面版。
- `update.json`、`sha256.txt`：版本信息与完整性校验文件。

本版本暂不发布 Android APK。Windows 包尚无可信代码签名，仅供从官方 Release 主动下载并核对 SHA256 后手动安装；应用内安全更新器会继续拒绝未签名包。

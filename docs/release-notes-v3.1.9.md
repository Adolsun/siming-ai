# Siming 3.1.9

Siming 3.1.9 是对 3.1 对话式立项计划的逐项复核版本。复核发现 3.1.8 虽已暴露暂停、继续和重试工具，但立项运行没有持久处理器；本版本补齐真实执行语义并统一状态契约。

## 主要变化

- 立项 Run 与 Operation 统一公开 `waiting_user`，兼容读取旧 `waiting_author` 数据；迁移会将旧运行状态规范化。
- 立项任务支持检查点暂停和继续：暂停不会丢失已完成阶段或草稿，继续使用当前 revision，并跳过本 Run 已完成的阶段。
- Operation 中心、立项工作台和 AI 助手共用暂停、继续、取消与重试处理器；聊天中的“停止/取消/暂停/继续/重试/切换模型后重试”走确定性控制，不交给模型猜测。
- 项目助手的 SSE `run` 事件会立即绑定 `operation_id`；停止按钮先取消后台 Operation，再断开前端订阅，避免“界面停了、后台仍写入”。
- “确认并继续”改为 `confirm_and_generate_recommended` 单一后端动作，记录明确 action type，并用 Idempotency-Key 恢复重复请求。
- 模型结构修复仍只向前端展示受限摘要，但完整原始回复会持久保存到 Run 诊断字段，便于排障且不会覆盖已确认原稿。

## 计划完成度复核

- P0：统一状态、即时消息、数据库幂等、取消/暂停/恢复、确认语义均有后端合同与前端入口。
- P1：聊天内立项、类型化工具、软依赖与 stale、原子 Patch、长文本导入、四级结构恢复均已落地。
- 原计划 3.2 范围已在 3.1.x 完成：实体持久化、实体级生成、通用依赖图、一致性校验、无限制 artifact 历史与差异恢复、统一会话 scope。

## 升级说明

- 新增 `300a10_creation_run_diagnostics` 非破坏性迁移，为立项 Run 增加完整模型诊断，并规范旧等待确认状态。
- Android 版本为 `3.1.9`，`versionCode` 为 `30109`，与桌面版本一致。
- UI 已在 1920×1080 和最小支持视口 800×600 审查运行中、暂停、继续、失败与等待确认状态。

# Siming v3.1.4

3.1.4 完成立项模型结构化输出的四级恢复闭环，减少因 JSON 语法或局部字段问题导致的整阶段重试。

## 四级结构恢复

- 第一级直接解析标准 JSON，并兼容代码块和前后说明文字。
- 第二级确定性修复中文引号、尾随逗号、意外未转义引号和被 token 限制截断的对象/数组。
- 第三级把原始回复、结构契约和校验错误交给同一模型，只修结构，不重新创作内容。
- 第四级在初次生成仍不完整时，保留可识别字段并用当前 contract baseline 补齐最小安全结构。

## 数据保护与可诊断性

- refine 连续修复失败时保留当前正确 artifact，不写入未修好的候选草稿。
- 初次生成的安全草稿不会覆盖已确认数据，仍需要作者审阅确认。
- 每次修复在持久 run event 中记录 `repair_method`、警告、校验错误和受限长度的原始回复摘录。
- 任务卡继续明确区分模型原稿、模型结构修复、确定性修复和安全草稿来源。

## 验证

- 新增中文标点、尾逗号、截断 JSON、无需第二次模型调用的确定性恢复、部分创意保留和 refine 原稿保护测试。
- deconstruct 与立项流程复用同一截断修复核心，避免两套算法继续漂移。

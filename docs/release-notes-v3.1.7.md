# Siming 3.1.7

Siming 3.1.7 继续收拢对话式立项的状态与数据边界：持久对话现在带有统一的系统、立项或作品 scope；人物、地点、分卷等对象可作为单独生成目标；立项面板可以直接运行跨 artifact 与实体引用的一致性检查。

## 主要变化

- 为系统助手会话增加 `scope_type`、`scope_id` 与作品关联，立项会话可在刷新后恢复自己的上下文归属。
- 阶段任务支持 `entity_id` 和 `entity_type`，定向调整时只合并目标对象，其他对象保持不变。
- 实体生成继续遵守 revision 写入保护和作者锁定字段；无法安全生成新对象时不会复制已有对象。
- 新增通用依赖图，统一表达 artifact 的软依赖、影响依赖、实体包含与实体引用关系。
- 新增确定性一致性检查，识别悬空引用、孤立场景、同名实体和 stale artifact，并返回稳定问题码。
- AI 助手右侧立项面板显示一致性结论和首个待处理问题，支持手动重新校验。

## 数据库迁移

升级会执行 `300a8_unified_conversation_scope`。现有系统助手会话会按 `creation_session_id` 自动归类为立项 scope；其他会话保留为系统 scope。

# Siming 3.1.12 测试版

本地测试候选包，暂不发布。

## 对话式立项

- 单一创意方向改为完整宽度的直接结果，不再保留三选一编号和批量生成入口。
- 确认创意只确认当前内容，不会自动生成世界观或全部后续阶段。
- AI 助手的立项数据面板可直接查看结构化原文，无需进入立项工作台。
- 从聊天打开完整编辑器时携带会话标识，工作台提供“返回原对话”入口。
- 聊天支持新增单个或多个角色、关系、地点、势力、分卷和章节细纲，并保留已有同类数据。
- 立项对象仍可任意顺序生成；缺少软依赖只提示质量影响。
- 立项会话和小说项目助手均改为由模型读取授权工具目录并自主选择工具，不再用“第一章/第1章”、对象关键词或数量正则预判操作。
- 创意方案按钮也只发送明确的对话指令，不再由前端绕过模型直接审阅并创建作品。

## 模型输出健壮性

- 阶段生成不再固定限制为 6,000/12,000 tokens，改用当前模型与上下文治理允许的有效输出上限，最高可配置 1,000,000 tokens。
- JSON 解析会忽略 `<think>`、`<thinking>` 和 `<analysis>` 内容，并从解释文字、代码块和多个对象片段中选择完整的最终结构。
- 保留尾逗号、非标准引号、意外引号和截断 JSON 的确定性修复与同模型结构修复。

## 本地验证

- 前端相关测试：34 项通过。
- 后端 JSON 与实体级生成测试：9 项通过。
- 前端生产构建通过。
- 界面验收和正式发布等待产品负责人确认。

# Siming v3.1.2

3.1.2 是对话式立项计划的第二批更新，重点建立聊天控制面与结构化立项事实面之间的实时连接。

## 助手内立项数据

- AI 助手右侧新增可折叠“立项数据”面板，集中展示作品定位、创意方案、文风世界观、角色关系、地点势力、主线卷纲、开篇细纲和完整性检查。
- 每项数据展示当前状态、来源、锁定数量、失效原因和正在运行的任务。
- 可以在聊天页直接确认阶段，或将目标明确的调整要求带回输入框，不再依赖页面跳转。
- 宽屏使用固定数据轨，最小支持视口使用覆盖式面板，完整编辑器继续保留为高级入口。

## 类型化立项工具

- 新增 artifact 查询、列表、依赖分析、原子补丁、字段锁定和解锁工具，并同步开放 REST 与 MCP 契约。
- 所有写入必须携带 `expected_revision`；版本冲突时不会覆盖服务器上的新内容。
- 局部补丁使用 JSON Pointer 路径，支持设置、替换、追加、删除和数组缩放。
- 已锁定路径及其父子范围禁止被补丁修改；失败的补丁在提交前回滚，原数据保持不变。
- 修改成功后复用现有检查点和下游 `stale` 标记，并返回明确的修改与影响摘要。

## 可靠性修复

- 恢复缺失的阶段确认 API 路由，使“确认当前内容”保持为独立、确定性的操作。
- OpenAPI 类型、工具注册表和工作区提示契约同步更新。
- 新增 artifact 原子性、锁定范围、依赖影响、路由契约和助手数据面板测试。

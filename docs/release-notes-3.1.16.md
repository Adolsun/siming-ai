# 司命 3.1.16

本版本修复本地 CLI 对项目任务的识别、MCP 工具可见性、章节正式写入与任务结束流程。

## 修复与改进

- 工作台请求先交由所选本地 CLI 模型判断执行线路，不再依赖固定措辞或正则匹配用户意图。
- 建档、立项、章节创作等需要写入的任务统一通过司命 MCP 工具操作数据库；普通讨论继续使用只读线路。
- 修复 Windows 下 OpenCode `.cmd` 启动时多行任务提示被截断，导致 CLI 只能读取资料却看不到写入工具的问题。
- 修复受管上下文与 MCP 工具调用之间的 `run_id` 传递及事务提交状态，避免工具已执行却被误判失败或超时。
- 章节写入完成质量记录与写后归档后，司命会根据数据库结果自动结束本地 CLI 进程，避免继续空转或重复清理。
- 没有明确章节编号时，可依据项目状态选择首个尚未写入的章节大纲。
- 改进本地 CLI 写作任务提示，要求直接保存完整正文草稿并优先完成正式入库与归档。

## 发布资产

- `Siming.exe`：Windows 桌面版。
- `update.json`、`sha256.txt`：自动更新与完整性校验文件。

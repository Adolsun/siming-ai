# 司命 3.3.14

3.3.14 改善章节建档的可靠性，并修复 PC 与手机端草稿状态和助手消息顺序问题。

## 章节建档与失败恢复

- 暂停、取消会停止在途任务；继续时等待旧任务退出，避免新任务被旧任务的清理或迟到错误覆盖。
- 完整事实响应成功解析后才保存检查点，中断后不会把半份事实当作已完成结果。已提交的有效结果、作者控制状态和已应用候选得到保留。
- 重试按章节、阶段分别计数，并向同一模型提供具体校验错误和已保存候选。认证、权限、请求过大等明确拒绝不再重复发送相同请求。
- 本机 CLI 持续输出却没有候选保存进展时会停止，连续无效候选提交也有明确上限；停止后保留检查点和实际错误，减少无效空转。

## API、CLI 与工具参数契约

- API 工具、MCP 与 API JSONL 使用同源候选字段校验，明确角色枚举、数组、关联、覆盖清单及批量限制。
- 参数错误会返回具体字段位置和修复指引；移除按自然语言猜候选类型或拆分字段的旧逻辑，由当前模型按契约修正。
- 立项工具连续写入失败时显示实际参数问题，不再笼统提示作者检查资料结构。
- 内容未变化的大纲保存不再使待确认提案误报过期；真实版本冲突继续受到保护。

## 草稿状态与助手消息

- 每个模型步骤读取当前草稿和建档状态。作者保存、建档完成后，历史中的“尚未保存/建档中”不会继续充当当前阻塞条件；正文再次修改后会重新要求建档。
- PC 建档通知按活动时间插入对话；手机工具记录归到对应回复下并默认折叠，避免旧记录堆在最新用户消息之后。
- 手机端服务器返回没有待保存草稿时清除旧状态；保存、丢弃、编辑和切换项目后的迟到请求不能恢复旧草稿。
- 手机端连续发送相同文字会分别显示，历史会话读取不会覆盖正在执行的新回合。

## 手机端说明

手机独立模式可以读取本地资料、生成和保存草稿，并检查本地正文是否需要重新建档。当前版本执行完整章节建档仍需连接 Gateway；缺少建档状态的旧项目资料需要同步后再继续写章。本版没有将这一既有能力缺口描述为已实现。

## 验证与下载

发布前测试包已通过作者测试。Android 全量 292 项单元测试及草稿状态、API/CLI、建档参数、任务恢复和消息顺序专项回归通过；标签发布流水线再次执行质量检查、安装冒烟测试和发布附件验证。

正式附件：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包。
- `Siming-apk-sha256.txt`：Android 安装包校验值。

正式 APK 使用现有发布证书，应用 ID 为 `com.siming.mobile`。此前 `com.siming.mobile.debug` 测试版使用独立数据空间，切换到正式版时需在正式版中配对或导入项目。

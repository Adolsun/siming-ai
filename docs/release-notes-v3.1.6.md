# Siming 3.1.6

Siming 3.1.6 将立项草稿中的关键数据投影为可定位的独立实体，并为每次数据变更建立不可变版本记录。

## 新功能

- 人物、人物关系、地点、势力、世界关系、分卷、章节细纲和场景细纲可作为独立实体查询、局部修改或软删除。
- 历史草稿会在首次访问时自动投影，实体 ID 在后续修改中保持稳定。
- 保存、AI 调整、导入、锁定、撤销与恢复都会生成不可变版本。
- AI 助手可通过类型化工具列出实体、定位单个实体、原子修改或删除，以及查看差异和恢复历史版本。
- AI 助手的立项数据面板新增版本历史与差异审阅界面。

## 安全性与兼容性

- 实体修改、删除和版本恢复都要求 `expected_revision`，旧任务不能覆盖作者的新修改。
- 锁定字段继续受保护；删除人物、地点或势力时，关联关系在同一原子写入中清理。
- 恢复旧版本不删除更新的历史，恢复前状态仍可再次查看或恢复。
- 数据库迁移会保留现有立项草稿，并在访问时渐进建立实体与基线版本。

## 验证重点

- 数据库迁移与旧草稿兼容。
- 实体局部修改、依赖关系清理、锁定拒绝与 stale 传播。
- 多版本差异、历史恢复与 revision 冲突。
- 1920×1080 与 800×600 下的历史审阅和恢复流程。

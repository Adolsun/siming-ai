# Siming 3.1.11

Siming 3.1.11 让对话式立项从“多方案抽选”进一步转向围绕一套作品方向持续协作，并修正模型配置和任务时间显示中的重复操作。

## 对话式立项

- 创意方向默认只生成一套，作者可继续通过聊天局部调整，不再先生成三套供抽选。
- AI 助手单条消息明确支持最多 1,000,000 个字符。
- 无作品或立项会话中的消息超过 20,000 字符时，原文会完整保存并进入持久化分块导入；刷新或关闭页面不会丢失，模型也不会被迫一次吞入全部原文。
- 旧版完整蓝图入口同步只返回一套方案，避免新旧入口语义分裂。

## 模型与任务

- 已保存的 API 密钥在查看模型列表、切换默认模型和真实连接测试时可直接复用；留空不会清除或覆盖原密钥。
- OpenCode CLI 配置会由司命运行 `opencode models` 获取当前可用模型，同时保留手动输入兜底。
- 模型标识长度上限由 100 提升至 512 个字符，长厂商路径和版本化模型名称可完整保存、切换并调用。
- Operation 时间统一携带 UTC 偏移，任务中心使用用户设备当前时区显示绝对时间戳。

## 版本

- Windows、Android 与 Gateway 统一为 3.1.11；Android `versionCode` 为 `30111`。

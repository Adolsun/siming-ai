# 司命 3.4.1

3.4.1 修复 Android 导入司命项目包后部分资料为空的问题，并允许首次启动时跳过 API 与 Gateway 配置，直接使用本机作品库。

## 手机项目包导入

- 修复完整项目包在 PC 能正常查看，但手机端大纲、世界观、伏笔和叙事治理页面显示为空的问题。
- 使用与 PC 相同的记录类型和 ID 映射契约，恢复卷、分区、章节层级，大纲关联角色及治理资料引用。
- 正确区分当前资料、历史版本、摘要和检查点，避免导出时混入错误的数据集合；保留原包中的其他资料。
- 角色能力、别名、设定资料及关系字段按 PC 数据契约恢复。

**此前已经导入且显示异常的手机项目不会自动修复，请升级后重新导入原始 `.siming-project` 项目包。** 重新导入前如已在手机上编辑资料，请先导出项目包保存这些修改。本次运行时业务修复集中在 Android；PC 导入逻辑保持原有实现，并新增共享样例回归测试验证两端契约。

## 稍后配置

- 首次启动新增“稍后配置”按钮，无需配置 API、连接电脑或 Gateway，即可进入本机作品库，导入、查看和手动编辑资料。
- 记住跳过配置的选择，重新启动应用后仍可直接进入作品库。
- 需要使用 AI 或跨设备同步时，可从设置继续配置 API 或连接自己的 Gateway。

## 测试范围

- 使用不含用户作品的共享样例，验证 PC 与 Android 项目包导入、卷章层级、角色关联、治理记录和导出后重新导入。
- 发布前本地检查通过：Android 333 项单元测试、Lint 无错误，后端项目包与打包契约 33 项测试通过。
- 在隔离 Android 模拟器中验证无 API、无 Gateway 的首次启动、跳过配置、重新启动及设置入口；同时检查经过压缩优化的测试 APK 能正常完成这些操作。
- 用户已完成本轮手机测试并确认发布。正式安装包由标签发布流水线重新构建，执行前后端、Android、Windows 安装冒烟以及发布后下载校验。

**AI 实际运行问题分析与测试主要基于 DeepSeek API 的 `deepseek-flash`；使用其他模型或 CLI 可能存在未知 bug，尚未完成同等实机验证。** 本次项目包与启动入口验证不需要调用模型，自动化协议测试也不代表其他模型或 CLI 的实机验证。

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包，可升级已有正式版；此前的 Debug 测试版使用独立应用标识，资料不会自动合并到正式版。
- `Siming-apk-sha256.txt`：Android 安装包校验值。

# 司命 3.1.14

本版本修复新书立项工作台的两个数据与流程问题。

## 修复

- 修复编辑“创作约束”后，确认下游阶段可能用旧表单覆盖上游修改的问题。已有草稿中发生过数据分叉时，也会优先保留较新的约束内容。
- 修复后端允许自由生成、但前端仍禁用未按顺序阶段的问题。现在世界观、角色、地点、卷纲、前 3 章细纲和最终审阅可以按需进入并生成。
- 更新立项工作台提示文案，明确缺少软依赖只影响生成质量，不再误导用户必须按固定顺序操作。

## 发布资产

- `Siming.exe`：Windows 桌面版
- `Siming.apk`：Android 客户端
- `update.json`、`sha256.txt`、`Siming-apk-sha256.txt`：自动更新与完整性校验文件

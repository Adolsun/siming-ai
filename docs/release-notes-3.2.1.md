# 司命 3.2.1

3.2.1 是 3.2.0 的稳定性与闭环体验补丁，重点修复章节完成后的自动建档反馈、任务状态同步、桌面重复启动和 SQLite 并发写入问题，并继续收敛 API 与本地 CLI 的行为差异。

## 主要改进

- 章节生成或修改后统一进入现行作品建档流程；聊天区会显示正在建档、等待确认、完成或失败状态，并提供直达作品建档页的按钮。
- 修复建档实际完成后任务中心仍显示运行中、连接中断或旧状态的问题；API 与本地 CLI 共用同一套运行状态投影和启动恢复逻辑。
- 改进自动建档的候选覆盖、人物别名归一和缺失信息处理，减少无意义重试、脏卡、空候选以及自动模式下不必要的人工确认。
- 统一项目助手消息时间戳的解析与显示规则，避免 UTC、本地时间和无时区时间混用造成的异常时间。
- 增加桌面单实例与端口接管机制，重复启动时优先唤起现有窗口，并清理失效的本机服务，降低端口占用导致的启动失败。
- 为 SQLite 写入增加协调、忙等待和恢复机制，降低项目助手会话、建档任务等并发更新时出现 `database is locked` 的概率。
- 快速开始在已经存在可用模型时复用检测结果，不再反复探测；同时补强模型请求覆盖、OpenCode 引导和本地 CLI 运行时的错误处理。
- Android 端补齐立项、项目助手和 PC 同源创作接口，支持在配对通道中选择 PC 模型或使用端侧加密的私有模型凭据，并加强离线数据升级与同步契约。
- 加强“去除 AI 味”的提示词、验证规则和验收用例，并补充章节改写、建档、MCP、移动契约和发布路径的回归测试。

## 发布资产

- `Siming.exe`：Windows 10 x64 或更高版本桌面版。
- `update.json`、`sha256.txt`：版本信息与完整性校验文件。
- `Siming.apk`、`Siming-apk-sha256.txt`：使用司命长期发布密钥签名的 Android 客户端及校验文件。
- Gateway 容器：随 Release 构建并发布 `amd64` 与 `arm64` 镜像。

Windows 包尚无可信代码签名，仅供从官方 Release 主动下载并核对 SHA256 后手动安装；应用内安全更新器会继续拒绝未签名包。

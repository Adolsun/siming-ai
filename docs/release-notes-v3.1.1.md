# Siming v3.1.1

3.1.1 是对话式立项计划的第一批可靠性更新，重点修复状态、消息和重复任务问题。

## 对话式立项

- 新书采访结束后留在 AI 助手，不再强制跳转立项工作台。
- 聊天中展示持久立项任务卡，包含真实模型、状态、停止、重试和完整编辑器入口。
- 支持在聊天中定向生成或调整创意、世界观、角色、地点势力、卷纲和开篇细纲。
- 用户消息立即保存，并创建运行中的助手占位消息；动态问题、任务、失败和中断状态可恢复。

## 可靠任务

- 阶段结果保存后进入“等待作者确认”，不再投影为失败。
- 新增数据库级立项任务 Claim，相同请求和断线重试只会恢复已有任务。
- 失败、取消和应用重启都会释放活动 Claim，可安全重试。
- SSE 支持事件序号续订，并在所有等待或终止状态结束连接。
- 可按最新草稿和当前选择模型重试失败、取消或中断的任务。

## 数据安全

- 作者确认后才把等待中的阶段运行标记为完成。
- 人工编辑期间的 revision 保护、作者锁定内容和安全草稿回退继续生效。
- 系统助手消息记录运行 ID、Operation ID、消息类型和结构化载荷，重启后遗留消息明确显示为已中断。

## 发布可靠性

- Android 签名校验改为读取 `apksigner` 原始输出，兼容 GitHub Windows Runner 的输出包装与不同 build-tools 标签格式。

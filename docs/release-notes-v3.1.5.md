# Siming v3.1.5

本版本把“把现有大纲整理成司命数据”升级为可恢复、可预览、可追踪的持久化导入流程。

## 对话式资料导入

- AI 助手附件支持 `txt`、`md`、`docx`、`json`，浏览器上传真实二进制文件，不再把 Word 文件误当纯文本读取。
- 没有立项会话时自动创建会话；上传后不强制跳转工作台，可继续留在聊天中查看进度。
- 聊天显示资料导入任务卡、分块进度、识别数量、冲突数量、停止、检查点重试和预览入口。
- 页面刷新或从任务中心返回时，可按 `creationSession/import` 恢复同一导入任务。

## 持久任务与数据安全

- 新增导入运行和导入分块持久表，原始文件、SHA-256、输入 revision、Operation、分块内容、提取结果和检查点均可恢复。
- 同一会话重复上传同一文件只返回原任务；重试通过状态条件更新抢占，避免重复执行同一分块。
- 应用重启会把失去执行器的导入标为 `interrupted`，保留已完成分块并允许继续。
- 等待预览时 Operation 使用 `waiting_user` 且关闭取消入口；取消不会写入半成品。

## 预览、冲突与来源

- 预览汇总人物、势力、地点、卷纲和章节摘要，并标出重复候选、现有数据、确认状态和锁定冲突。
- 可选择全部或部分对象，使用“合并”“覆盖未确认数据”“跳过冲突”策略。
- 写入携带 `expected_revision` 并在同一数据库事务中校验；revision 变化、Schema 校验失败或锁定冲突时原数据保持不变。
- 每批导入数据记录 `source_file_id`、`source_chunk`、`source_message_id`、`import_run_id` 和置信度。
- 新增 `import_creation_material`、`preview_creation_import`、`apply_creation_import` 类型化工具供助手调用。

## 验证

- 后端覆盖 30,000 字以上分块、格式解析、同文件幂等、检查点恢复、冲突预览、revision 冲突、锁定保护和来源链。
- 前端覆盖真实 `File/FormData` 上传、任务恢复、预览选择与应用。
- 完整发布门禁继续验证前后端、Android、桌面包、发布资产及 Gateway 多架构镜像。

# 司命 3.3.17

3.3.17 修复立项写入后总结失败、势力和首版卷纲生成报错、前三章细纲为空或挂错卷，以及建档后角色页仍显示旧版本、大纲未关联角色的问题。

## 测试范围与已知限制

**本次实际模型联调、问题复核和人工测试基于 DeepSeek API（`deepseek:deepseek-flash`）。使用其他模型或 CLI 接入时，可能存在尚未发现的 bug。**

自动化回归包含模拟模型接口、隔离数据库及 API／MCP／CLI 契约测试；这些检查不能代替其他模型或 CLI 的完整实机验证。目前尚未完成同等范围的跨模型、跨 CLI 测试，使用时请核对实际保存结果，并在反馈中注明模型、接入方式与错误提示。

## 立项生成与回执

- 缩小写入回执，只向总结模型提供真实状态、实体 ID、阶段、revision 和保存结果，避免完整阶段正文挤占回执容量，导致实际写入成功却被模型误认为失败。
- 势力和地点生成使用明确的实体集合与类型枚举；参数或模型结构错误会返回具体字段和修正说明。
- 首次生成卷纲实体时保留完整主线、核心冲突、结局方向及卷集合，区分“任务已启动”与“结果已保存、待确认”。
- 模型输出无效时由同一模型修正；仍失败则保留既有资料，不重复执行已经成功的写入。

## 细纲正文、卷归属与人物绑定

- 章节和场景必须提供非空细纲正文；不能仅把内容放在目标、事件或章末钩子字段中。
- 章节通过真实卷 ID 归属到卷，场景通过章节引用归属到章；调整卷顺序不会改变章节归属。
- 立项和建档统一使用明确的角色 ID 绑定章纲与场景，验证其存在及作品／会话归属，不从自由文本猜测关联。
- 支持同一轮新建角色后绑定到场景，章节人物清单同步到章纲；缺失、无效或未实际写入的关联会进入校验反馈。

## 角色资料显示与手机端

- 建档进度更新或结束后，工作区自动刷新角色、版本和关联资料；聊天面板关闭时同样生效。
- 后台迟到响应不会覆盖作者正在编辑的未保存内容。
- 基础信息、剧情状态、写作约束按正文事实和模型提交内容更新，不强制改写没有新信息的字段。
- Android 独立立项同步生成校验、人物引用、正式建书关联及修改回执；转交 PC 时使用明确 ID 映射。

升级不会自动补写旧资料中缺失的细纲正文和人物关联，需要重新完善相应资料。

## 验证与下载

本轮修复已通过 698 项后端回归、11 项前端定向回归、56 项 Android 立项测试及相应质量检查。打包程序使用隔离数据验证了三章九场景、正确卷归属和 24 条正式人物关联。正式附件由标签发布流水线构建，并执行发布检查、安装冒烟及下载校验。

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包。
- `Siming-apk-sha256.txt`：Android 安装包校验值。

# Siming v3.1.3

3.1.3 是对话式立项计划的第三批更新，重点解除固定向导顺序，并让局部修改的影响和恢复路径更精确。

## 非线性立项

- 世界观、角色、地点、卷纲和开篇细纲可以按需生成，不再要求所有前置阶段先确认。
- 缺少规划资料时显示软依赖提示，明确说明仍可生成以及可能影响的质量，不再将提示伪装成硬阻塞。
- 创建正式作品等真正需要完整数据的操作继续执行硬依赖校验。

## 精确影响范围

- 使用显式影响图替代“后续阶段全部失效”的顺序推断。
- 修改角色时只标记卷纲、开篇细纲和完整性检查为需要校验，不再无差别标旧地点与势力。
- 依赖查询和局部补丁结果返回一致的受影响对象摘要，已有下游数据始终保留。

## 安全撤销

- 立项数据面板显示检查点可用状态，并提供“撤销最近一次修改”操作。
- 撤销请求必须携带 `expected_revision`；版本冲突时拒绝覆盖较新的人工修改。
- 撤销恢复结构化检查点，但不会错误地把已经受影响的下游数据重新标记为有效。
- 新增 REST、工作区工具和 MCP 契约，AI 助手也可执行同一确定性撤销操作。

## 验证

- 新增非线性生成、软依赖、精确 stale、检查点撤销、版本契约和助手面板交互测试。
- 同步更新 OpenAPI 客户端、Android 与桌面版本元数据。

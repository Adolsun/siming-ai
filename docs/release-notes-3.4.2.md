# 司命 3.4.2

3.4.2 修复手机导入项目包后无法继续写章，以及本机导入作品被误判为已同步、无法离线删除的问题。PC/Gateway 同步修正项目包导入时的章节建档状态恢复；桌面界面没有功能调整。

## 导入后续写与建档状态

- 完整项目包导入后，根据同一章节的当前版本正文快照和后续建档摘要恢复建档状态。证据完整的已建档章节可以通过续写检查，无需为了补齐这个状态先连接 PC。
- PC/Gateway 与 Android 使用相同规则及共享样例验证；旧版本快照、已修改正文、过期摘要或缺少证据时仍要求建档，避免把未建档的正文误判为已完成。
- Android 升级时一次性修复已导入作品缺失的建档状态，保留正文、已知状态、同步修订和待同步编辑。
- 导出并重新导入时维持相同检查规则，项目包 v1 格式保持不变。

3.4.1 导入且已保留完整快照、摘要的手机作品通常无需重新导入。若使用更早版本导入，导致这些资料本身没有恢复，需要重新导入完整原包；手机已有修改时，请先导出保存。此修复恢复的是已有建档证据，手机独立模式下新生成章节仍先“仅保存”，启动后续建档仍需连接 Gateway。

## 本机作品状态与删除

- 尚未上传的导入作品正确显示“仅本机”，无需 Gateway 即可删除。已配置但暂时无法连接 Gateway，也不影响删除尚未上传的本机作品。
- 删除时清理作品副本、保留的原包及待同步记录，不会为了删除先把作品上传到 PC。
- 真正已同步的作品仍通过 PC 同一删除 API 处理；上传中断、回执未确认时提示联网核验。
- 删除与导入、后台同步串行执行。若确认删除后同步状态发生变化，重新确认删除范围，避免扩大原本只删除本机作品的操作。
